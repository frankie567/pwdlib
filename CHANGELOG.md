## [0.4.0] - 2026-11-14

### Added

- Support Python 3.15.

### Changed

- Publish GitHub build provenance and PyPI attestations for release distributions.

### Removed

- Drop Python 3.10 support. Python 3.11 is now the minimum supported version.

## [0.3.1] - 2026-08-12

### Changed

- Remove the upper bound on the Argon2 dependency.

### Fixed

- Correct the dependency versions for Python 3.10 compatibility.
